# Concept sources and implementation boundaries

Use this map when a lesson's claim needs a firmer reference. Pick the row for
the mechanism you are implementing; reading the whole bibliography is not a
prerequisite. Basic graphics and linear algebra are assumed. The sources were
checked on November 3–4, 2026, and Chapter 42's on November 9; the limits
below distinguish full text, author summaries and unavailable artifacts.

A specification defines an API contract. A paper describes an algorithm under
its assumptions. This project's source and tests define its chosen variant.
An attractive capture, a quiet validation layer and a paper citation provide
different evidence. Current online documentation can describe features newer
than this project's Vulkan 1.3 / C++20 baseline; use the vendored revision and
enabled device features when assembling code.

For GPU timing claims, use the [timestamp contract](21-GPU-Particles.md#8-what-each-pass-costs)
and the actual marker positions. The [sea](30-A-Rougher-Sea.md#sea-timing-intervals)
and [Horizon](37-Objects-At-A-Distance.md#horizon-timing-intervals) maps show how
later features enter the intervals; their legacy labels do not isolate kernel
costs. Reused-slot results and device-specific measurements have different
roles from dispatch counts and workload predictions.

For water normals, distinguish the current unchopped height-slope encoding
from the displaced surface's parametric normal. The
[optional tangent derivation](29-FFT-Ocean.md#ocean-parametric-normal) uses
[PBRT's surface interaction discussion, §3.11.1](https://www.pbr-book.org/4ed/Geometry_and_Transformations/Interactions)
for the tangent/orientation distinction. It derives the signs from this
project's displacement convention. A horizontal projected-area determinant
is not the full surface-area scale, and recovering slopes after filtering
stored unit normals is approximate. The shared Ocean/Sea image contract must
change with any representation upgrade.

## Retrieval limits and how to use the evidence

The clustered-lighting and Guerrilla placement rows use the
authors' accessible summaries where full artifacts
were blocked or exceeded fetch limits. Rockenbeck's original 2021 PDF was
located through GDC's official slide entry but initially returned HTTP 403;
the later text-only retrieval is described below. No exact game equation is
attributed to an uninspected diagram. Hillaire's large paper was
unavailable to the reader; the author reference implementation was inspected.
Original normal-filtering papers named in 48 were not fully retrieved.

Wohllaib's full grass PDF was subsequently downloaded from GDC and its mirror,
with matching SHA-256 hashes. Selected text and rendered pages were inspected;
the row above identifies the verified subset, not a full visual-deck review.

Jahrmann/Wimmer's full author-hosted draft was also retrieved, with relevant
method text and pp.5–6 equations inspected. Its printed culling inequalities
(17, 20) conflict with adjacent prose. This is an observed draft contradiction,
not a verified erratum; Chapter 26's qualitative comparison does not copy them.

A later retrieval exposed cached text from Rockenbeck's original PDF: it
names direction, noise, vorticles and displacement, plus distinct source and
particle compute-stage labels. Diagram screenshots still failed with cache
miss/403 responses. This strengthens the primary evidence for the broad wind
architecture; it does not verify a visually presented equation or data layout.
